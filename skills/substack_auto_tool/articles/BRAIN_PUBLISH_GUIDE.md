# Brain 出品ガイド — 有料記事の登録手順

このフォルダの素材は **Brain（brain-market.com）** への出品を想定しています。  
Substack ではありません。

## ファイルの使い分け

| ファイル | Brainのどこに貼るか |
|---------|-------------------|
| `assets/brain_article_cover.png` | **サムネイル画像**（商品一覧・OGP） |
| `brain_listing_fields.md` | 商品名・キャッチコピー・価格など（入力欄メモ） |
| `brain_sales_intro.md` | **紹介文**（購入前に全員が読める販売ページ） |
| `brain_article_body.md` | **記事本文**（購入後にだけ読める中身） |
| `brain_paid_article_styled.md` | 上記2つを結合した参照用（分割前の全体版） |

## Brain の画面構成（イメージ）

```
┌─────────────────────────────────────┐
│  サムネイル（600×600 推奨）           │
│  商品名                              │
│  キャッチコピー                       │
├─────────────────────────────────────┤
│  紹介文  ← 購入前に見える（セールス）   │
│  ・悩み共感                          │
│  ・得られるもの                      │
│  ・向いている人                      │
│  ・先に結論                          │
├─────────────────────────────────────┤
│  [ 購入ボタン ]                       │
└─────────────────────────────────────┘
         ↓ 購入後
┌─────────────────────────────────────┐
│  記事本文  ← 購入者だけが読める        │
│  第1章〜付録                          │
└─────────────────────────────────────┘
```

Substack の「Paywall（有料ライン）」に相当するのは、Brain では **紹介文 と 記事本文 の分離** です。

## 出品手順（Brain管理画面）

1. [Brain](https://brain-market.com/) にログイン
2. **マイページ** → **記事を販売** → **新規作成**
3. 以下を入力：

| 項目 | 内容（例） |
|------|-----------|
| **商品名** | `brain_listing_fields.md` の「商品名」 |
| **キャッチコピー** | 80文字前後。一覧で目を引く1行 |
| **サムネイル** | `brain_article_cover.png` をアップロード |
| **カテゴリ** | ビジネス・マーケティング / 副業 など |
| **価格** | 980〜2,980円（初商品は 1,480円 前後が無難） |
| **紹介文** | `brain_sales_intro.md` をコピペ |
| **記事本文** | `brain_article_body.md` をコピペ |

4. **画像の挿入**（紹介文・本文それぞれ）
   - エディタの画像ボタンから `assets/` 内の PNG をアップロード
   - または Markdown/HTML が使える場合はパスを差し替え

5. **特典**（任意・推奨）
   - PDF：リサーチ15項目シート
   - PDF：公開前チェックリスト
   - テキスト：AIプロンプト5本

6. **注意事項**を紹介文末尾に記載（収益非保証・コピー禁止）

7. **プレビュー**でスマホ表示を確認

8. **公開**（または審査提出）

## 紹介文 vs 本文 — どこで切るか

| 紹介文（購入前） | 記事本文（購入後） |
|----------------|------------------|
| 導入・悩み共感 | 第1章〜第14章 |
| タイトル比較 | 具体的手順・テンプレ |
| この記事でわかること | AIプロンプト全文 |
| 向いている人 | 商品例・付録 |
| 先に結論 | まとめ |

**紹介文だけで「買う理由」が完結し、本文で「実践の中身」を渡す** 構成にします。

## LINE風装飾を Brain で再現するコツ

Brain のエディタは HTML 編集が可能な場合があります。

| 装飾 | Brain でのやり方 |
|------|-----------------|
| 吹き出し | 引用ブロック / `<blockquote>` |
| 区切り線 | `<hr>` または `---` |
| 強調 | **太字** / 見出し `<h2>` |
| 比較 | 画像 `brain_section_title_compare.png` を挿入 |
| チェックリスト | 本文末尾に画像 + テキストリスト |
| 表 | 画像化するか、シンプルな箇条書きに変換 |

Unicode の枠線（`╭─╮`）は環境によって崩れることがあるため、**重要な部分は画像**（用意済み5枚）で見せるのが安全です。

## 画像サイズの目安

| 用途 | サイズ |
|------|--------|
| Brain サムネイル | **600×600px**（正方形）※ `brain_article_cover.png` を Canva でトリミング可 |
| 本文中の図解 | 1200×675px（16:9）— 用意済み画像そのまま |
| X / Instagram 告知 | 1080×1080 または 1200×675 |
